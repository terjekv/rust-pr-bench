# Security Policy

## Supported versions

Before the first stable release, security fixes are applied to the latest commit on `main`.
After `v1.0.0`, the latest `v1` release line will receive security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting form in the repository's **Security** tab.
Do not disclose a suspected vulnerability in a public issue, pull request, or discussion.

Include the affected interface, reproduction steps, potential impact, and any suggested mitigation.
You can expect an initial acknowledgement within seven days. We will coordinate disclosure and a
release timeline with you after confirming the report.
